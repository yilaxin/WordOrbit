# 词汇真经 · 离线背词

这是一个个人离线学习版 PWA。当前词库已按《雅思词汇真经》22 个主题整理，并通过书末索引进行补录核对。正式练习默认只使用已审核词条，OCR 和索引补录词条统一放在“待核验词库”中。

## 使用

- 直接双击 `index.html` 即可使用核心功能；浏览器语音合成、localStorage、JSON 导入导出可用。
- 如需安装 PWA，请在该目录启动一个本地静态服务器（例如 `python -m http.server`），再用浏览器打开对应地址。
- 学习记录保存在当前浏览器本机。用“词库 → 导出数据”备份，用“导入 JSON”迁移。
- “混合练习”会逐题切换题型；“听音”是听英文后选择英文单词；“中选英”用于反向记忆。
- “待核验词库”可单独浏览和专项练习，不会污染正式练习的干扰项。
- 词条中文释义和音标现在由离线英汉词典数据统一补全；PDF 仅用于确认词表、词族和出处，不再直接把 OCR 片段当作正式释义。
- 提交答案后会显示词性、完整释义、按词义筛选的英汉对照例句和同词根/词族衍生词。例句数据随网站离线保存；未找到可靠例句的词会明确提示，不再套用通用模板。你在词库里自定义的例句仍会优先显示。
- “整本遍历”每轮从全书范围随机选 50 个词，优先选择尚未背过的词；不足 50 个时从其余词随机补齐。前 50 题英选中，后 50 题用同一批词中选英，两段题序分别打乱。任何答错的具体题目都会追加到原定 100 题之后，重做仍错则继续排到末尾。题目栏会显示待重做数量；原定题目未做完时不能提前跳入错题重做。保存后继续练习会保留原题序，不会重新抽词。
- “学习数据”页提供三种清空：本次训练、当天作答、全部学习数据。清空局部作答后会重算受影响词的熟练度；词库与个人笔记始终保留，全部清空时还会清除收藏。操作前会弹出确认，建议先导出备份。

## JSON 导入字段

每个词条至少包含 `word`、`meaning`、`chapter`；可选字段包括 `ipa`、`pos`、`example`、`exampleZh`、`collocations`、`etymology`、`source_page`、`tags`、`notes`。

## 资料边界

原 PDF 是扫描图像，没有文本层。OCR 词条会保留来源页并进入待核验区；确认释义和音标后，可在词库编辑中标记为已审核。静态词库与学习记录分开保存在浏览器本机，降低反复写入的数据量。

中文释义与音标补全使用 ECDICT 离线数据（MIT），词库运行时不依赖网络。

英汉对照例句部分选自 [Tatoeba](https://tatoeba.org/en/downloads)（文本按 CC BY 2.0 FR 授权，原始句子可通过数据内 `sourceId` 追溯）和 [OPUS Wikimedia 英汉平行语料](https://opus.nlpl.eu/Wikimedia.php)（CC BY-SA 4.0）；部分例句为本站按词义自行编写。语料已在本地按词形和中文词义筛选，仍可能存在语境或译法差异，欢迎在词库中修改个人例句。保留原资料署名与许可要求；本站不在运行时联网。

当前离线例句库收录 2512 条不重复的英汉例句；其余词条暂显示“暂无可靠例句”，不再展示套用模板造出的句子。这个覆盖量不等于全书例句已逐一校对完成。
