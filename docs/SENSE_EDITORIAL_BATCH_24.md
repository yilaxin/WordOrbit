## 筛选与数据边界

依据本次获授权继续使用的正常学习导出，结合公共 ID、归一化拼写、整词学习记录、逐题作答及完成记录，确认剩余 176 个正式词中有 172 个已学但尚未整理。本批全部纳入，不设仅限单个英文单词的过滤条件；carbon dioxide、el nino、new zealand 三个多词条目也纳入。172 词均有正向学习证据，无重复、缺失或未学混入。整词已学不自动标记新义项完成。

按用户要求，nino、primate、proliferate、sterility 四个待核查旧条继续跳过。正式词库共 4,247 词；本批后只有这四个尚未结构化，仍保留基础练习。el nino 与单独的 nino 是不同公共词条，本批不会借整理前者而自动认证后者。

学习导出、候选清单、核查摘要、私人审计及隔离测试目录仅保存在本机忽略目录，不进入 GitHub 或发行包。本批发布公共词条和项目原创教学例句；原词 ID、笔记、收藏、学习记录与续练格式保持兼容，私人词库、星云与生活彗星独立存储。

## 编辑范围与来源

逐词阅读实际词典条目，以 [Merriam-Webster](https://www.merriam-webster.com/dictionary/terminal) 核对词性与所采用的常用义项。[tropics](https://www.collinsdictionary.com/dictionary/english/tropics) 采用实际读到的 Collins 复数名词条目，[hip-hop](https://www.collinsdictionary.com/dictionary/english/hip-hop) 采用其音乐和文化解释；shame 的“令人遗憾的事”使用 [Collins shame](https://www.collinsdictionary.com/dictionary/english/shame) 的实际定义。plagiarise、recognise、sceptical 分别核对词典对应拼写 plagiarize、recognize、skeptical。

每个义项保存稳定 ID、词性、中文解释、必要构式、近义选项排除关系和一组原创英汉例句。390 句与实际读取的词典文本逐句比对，无整句照搬。明确限定教学范围，不声称穷尽全部历史、习语或专业义。156 组旧译参考说明保留未另立考点的原解释；未采用并不自动表示原译必然错误，也不据宽泛旧译生成独立正确选项。

terminal 分列交通站点、计算机终端、接线端子与末端、疾病晚期形容词。mount 八义覆盖山峰、坐骑、支架、登上、增长、安装、组织与装裱；print 七义分别配打印、出版、印刷体书写、字体、印记、图画与印花的语境。

[table](https://www.merriam-webster.com/dictionary/table) 的英式“提交讨论”与美式“暂缓审议”分别标注地区与构式，配互不混淆的例句。desert 按当前首音节重读采用沙漠名词与荒凉形容词，insult 按当前首音节重读采用名词；moderate 的 /-ət/ 采用形容词与名词，postulate 的 /-eɪt/ 采用动词。mouth 与 ferment 的来源确实列有与当前发音相容的动词或名词变体，故保留相应词性，不以绝对化的词性重音规则排除。

公共 ID el nino、new zealand 保持不变；例句使用规范名称 [El Niño](https://www.merriam-webster.com/dictionary/El%20Ni%C3%B1o)、[New Zealand](https://www.merriam-webster.com/dictionary/New%20Zealand)。X-ray、X-rayed 保留规范大小写。billion 采用现代十亿数词。hockey 的曲棍球与冰球分列；tropics 使用 the tropics。mad、crazy 采用生气、荒唐或狂热喜爱等语境，不把有冒犯色彩的旧人物标签作为中性疾病描述。

## 接入与验证

公共目录、按需词库、首页小型索引及离线资源接入第二十四批。前二十三批 4,071 个词条保持原样；全库 10,550 组例句无重复，172 个来源核查记录与公共词逐一对应。

本批保守关联 understand/comprehend、doubt/sceptical、inspect/examination、anxious/eager、damp/moist、cram/bolt 等近义表达，避免合理答案被用作错误选项；这些排除关系不表示一组词的所有义项完全同义。东北与西北、不同方向的来风、计算机终端与计算机指令、非凡人物与失败者、沸腾与冻结保留含义区别。

以完整 4,243 词池依次运行 50、50、50、22 词四轮，验证全部 390 个新目标、固定选项、无重复、无回忆降级和逐义完成，并回归历史批次与学习状态。新增多词条目学习证据检查、El Niño 词形检查、英美 table 用法检查；浏览器精确展开 table 四义和对应例句，验证续练、旧版 ID、备份恢复、清除及离线行为。桌面自检使用独立数据目录。

发布前检查暂存清单与机密；提交后重新构建，使下载包携带实际提交 SHA。源码和版本标签正常推送，Windows ARM64 ZIP 与 SHA-256 附件先上传草稿，核对内容后公开。
