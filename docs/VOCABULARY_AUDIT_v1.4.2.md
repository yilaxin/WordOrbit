# v1.4.2 全库释义与音标复查

核对日期：2026-10-22。对象是应用随附题库，不读取或修改“我的词库”和“星云”私人内容。

## 范围和结果

对原有 4,249 条随附词条进行全量结构筛查，再针对缺失、乱码、旧标音、疑似命令说明、只有拼写引用、漏掉常用义项及异读词等问题逐项查证。不是逐字重译 4,249 篇词典条目，也不把结构检查通过当作语义零错误的保证。

和升级前基线逐 ID 比较，148 条中文释义、118 条词性、811 条正式词条音标发生变化。音标数包括旧格式规范化，不表示 811 条全是读音错误。`catalog-repairs.js` 整理 153 份中文学习释义和 596 份逐词发音修订参考，其中部分与既有内容一致；其余变化主要为旧 ECDICT 前置点号次重音标记改写为 IPA 的 `ˌ`。不通过简单地将所有旧元音替换成另一元音来推测发音。

## 代表性修订

- `mall` 补充购物中心、商场等常见含义；`discipline` 补充学科等义；`make-up` 区分名词含义与短语动词，补充化妆品、构成等义。
- 移除 `data` 等词条夹杂的旧 DOS 命令说明，以及 `finger`、`flag` 中不适合该学习条目的命令文字；保留域名、二进制、通信协议等正常计算机义项，不因“计算机”字样一概删除。
- 修复 `linguistic`、`discernible`、`laptop`、`checklist`、`workforce` 等损坏标音，以及多词词条被截断的问题；修正 `alumni` 等读音。`coed` 使用男女同校义的 `/ˌkəʊˈed/`，不采用同名地名 Coed 的读音。
- `record`、`present`、`conduct`、`lead`、`content` 等在提交后的答案区显示常见词性/词义对应的读音说明，不提前泄露中选英答案。
- 以英式读音为主；`short-day` 使用所查词典明确列出的美式读音，词条元数据保留 US 标记。`utilities` 的规则复数、`ripener` 和 `coiner` 的派生读音在元数据中注明构词依据，不伪称来自独立的英式音标记录。

## 两个必须保留判断依据的条目

1. **pil → pill**：用 PDF 原页视觉复核，印刷词是 `pill`，不是 `pil`。与已存在的 `pill` 合并，避免重复出题；两条学习次数、正误次数合并，熟练度取较高值，保留最近学习日、较早到期日、收藏、尝试记录、笔记和标签，并映射旧 ID。重复启动不重复累加。此修正规则只针对原始 `ocr-pil` 条目，不全局更改用户私人缩写 PIL。
2. **revoltive**：原书印刷页确有该拼写，但本轮未能从所查 Cambridge、Collins 等主流词典核实其对应标准义项与发音。保留原形、来源和历史记录，单列“原书疑词”，不进入正式练习、整本遍历或干扰项；不保留猜测音标。资料区解释其与 `revolted`、`revolting` 的区别，不静默替换成另一单词。总库因此仍有 1 条无可确认音标的资料词，不能声称全库所有词均已查证。

## 升级与选项

直接启动新版应用，静态修订自动应用到原 ID，不需要清空学习数据。旧续练选项若已不属于现行完整释义，会重新生成；未提交题继续按当前答案判定，已提交题保留历史统计并标示词典更新，不重新计分。一般新题选项在选中后保持稳定。中文选项均取其它正式词条的完整学习释义，不截取首义项。整本遍历仍为随机 50 词的两个方向，错题追加末尾。

## 参考、边界与验证

语言事实参考 [Cambridge Dictionary](https://dictionary.cambridge.org/)、[Collins Dictionary](https://www.collinsdictionary.com/)；耐阴相关用法参考 [RHS shade gardening](https://www.rhs.org.uk/garden-design/shade-gardening)，结合现有 MIT ECDICT。逐词参考 URL 随修订数据保留。中文为简明学习义项整理，不复制网页正文、词典例句或音频，不保证覆盖一切专业、历史、地域义项；雅思也没有一个可据以保证“全部词义”的官方完备清单。

测试包括全库正式资格、音标结构与词性、4,247 词双向四选一的完整释义及去重、旧数据迁移、重复合并幂等、续练判题、提交前隐藏音标、窄屏和离线运行。既有私人数据库隔离测试继续保留。完整复查脚本 `scripts/Audit-Vocabulary.cjs` 仅在隔离浏览器运行，报告写入不发布的 `.build`。
