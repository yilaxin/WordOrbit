## 3. 先取得可信的学习状态，再选词

1. 优先从用户实际使用的词轨桌面应用中，通过公共词库页面的“导出数据”取得新的完整授权导出。只做正常导出，不答题、不清空、不导入、不修改学习记录。
2. 若使用 Windows 界面自动化，先读并遵守可用的 computer-use 技能；从实际返回的窗口选择词轨。不要误选隔离测试实例，也不要直接读写运行中的 WebView2 学习目录。
3. 验证导出存在且能解析，并具有有效 `exportedAt`、非空 `words`、对象型 `records` 和数组型 `attempts`。文件修改时间不能代替导出内部时间。
4. “未学”必须建立在该完整导出覆盖词表的基础上；导出中根本没有的词不能算未学。完整导出内没有该词的作答记录，与完全拿不到进度，是两种情况。
5. 以下任一迹象均排除：`records` 中 `seen / correct / wrong` 任一为正、存在 `lastSeen`、`attempts` 命中 `id` 或 `wordId`。还要归一化拼写，排除同词不同 ID 的已学记录。
6. 词源使用公共捕获表 `.build/vocabulary-audit-catalog.json`，只选 `formal === true` 的词；不得用私人词库、星云文章或生活彗星凑数。
7. 排除 `sense-catalog.js` 的**全部现有词键**，包括五个部分审核词；不能只按 `complete === true` 或只排除最新一批。
8. 选词时去除首尾空格、忽略大小写，并检查归一化后的 200 个拼写互不重复。需要同根词时也必须实际属于正式表、符合未学与未结构化条件，不能为了数量临时造词或扩大词库。

如果无法取得新导出：可以使用仍可读取、确有授权的较旧完整导出，但必须向用户说明时间与局限，不声称实时未学。如果仅有历史筛选结果、候选缓存或找不到原始导出，则不能把它们当完整学习状态；先把新词候选作为未确认草稿，明确说明仍需新导出，不假装完成未学筛选。

## 4. 词义整理的质量要求

- 逐词查阅 Cambridge、Collins 等词典原始条目；需要时可补查其他词典出版方的原始条目。搜索结果、原书 OCR 或已有中文串只能帮助定位，不是自动认证。
- 常用学习义尽量完整，区分会改变理解、词性或用法的真实义项。不限制每词两个义项，也不要为了增加义项数把完全相同的意思拆成多条。
- 不把英文词的整串旧中文释义直接当一个“新义项”；也不按分号分割后逐片段标为已审核。
- 每个保留义项需有稳定 `id`、清晰 `label`、正确 `pos`、`aliases`、语义标记 `concepts`、实际核对的 `source` 以及独立 `example`。
- 例句必须自然、语法正确、体现该义项的区别，包含目标词或正确屈折形式；中文准确表达对应句意。禁止用“The report highlights the role of WORD in modern society”等模板替换目标词。
- 中文句与英文句逐一对照，注意否定、时态、对象、因果、可数性和专业事实。程序只能检查字段，无法代替这一步。
- 给短语义明确 `construction`，使用支持该短语的来源。例如 `consist of` 与 `consist in`、`reckon on` 与 `reckon with` 不能省略搭配后混用。
- 英美拼写变体应指向实际列出该变体的条目；词典缺页或访问失败时换可核实的原始来源，不根据 URL 拼接结果假装查过。
- 技术意义优先查官方文档；例如软件 fork、文字 wrap、窗口 tile。保留具体术语范围，不能把专用缩写混成日常词义。
- 原创例句不复制词典例句；公开内容保持简洁归纳，不抓取并发布整页词典内容。
- 若发现旧释义疑似错误、过宽、词性错配或仅在生僻专业语境成立，应明确处理并保留旧译追溯。不能把未决项标成正确答案。
- `scope-excluded` 不是“已证明旧译错误”或“已证明旧译正确”，而是声明学习范围外。排除必须逐词具体解释；不能机械批量排除正常常用义，或仅为让审计归零而排除困难项。
- 真正尚未查明的旧译使用未决机制，保留 `complete=false`；不得为了达到 200 个“完整词”伪造通过。如果需换候选，应重新检查筛选证据并说明情况。
- 同义、近义和上下位关系要结合本词与历史批次检查。`concepts` 共享标记用于保守排除歧义，不表示两个词可以在所有句法下互换。

近期已纠正或明确边界的例子：cream/cheese、bulb/corm、embryo/fetus、mortal/dying、excrete/secrete、lane/单行道、语法 plural 的数量，以及句子 sentence 与逻辑命题的区别。不能把旧释义中仍保留的历史片段当作词典证据。

本任务聚焦新义项结构和例句，不批量改动正式旧词库的释义、音标、ID 或词数。若发现原词库其他问题，记录具体证据和范围，避免在本批中顺带扩大改动。

```js
[id, label, pos, aliases, concepts, englishExample, chineseExample, optionalConstruction]
```

`aliases` 和 `concepts` 最终均须为数组。若沿用批次帮助函数，可由它将单个概念字符串转为数组。`aliases` 用于旧译追溯和近义排除，不是可随意填入的近义词清单；稳定语义标记应复用已有合适概念。

注册后形成的义项结构为：

```js
{
  id, label, pos, aliases, concepts, source,
  construction: null, // 或已明确核对的搭配
  example: { en, zh, reviewed: true, origin: 'original-wordorbit' }
}
```

条目具有 `batch / reviewed / complete / reviewDate / scope / sources / referenceOnly / senses` 等字段。日期用实际整理日期。只有完成核对后才设置审核通过，不能用结构模板替代审核。

`add()` 按单词键赋值，重名会覆盖旧数据；因此注册前后都要验证重复，不能以“最终词数看起来够了”代替去重。

## 6. 出题核心必须保持的行为

这里只验证，若仅新增数据，通常不需要修改核心。

1. 从本轮未完成正式词随机选最多 50 个不同词，最后一批不足 50 不从下一轮补足。
2. 第一阶段每个已审核义项都有目标题；第二阶段每词反向关联，优先薄弱义；第三阶段多义检查分组。
3. 题量随实际义项数和错题增加，不固定 100，不要求每词恰好两题。
4. 错题追加到本轮真正末尾；原题及选项快照稳定；重复提交不重复计分；全部原始目标与追加错题都完成才结束。
5. 干扰项只能来自可信的其他词。正向题排除本词任意真实含义，反向题还检查候选英文的全部义项，避免同义词被标错。
6. 可信选项不足时明确降级为回忆自评卡，不编造干扰项；真实新批次还需记录是否发生降级并检查原因。
7. 未完整审核的词不能被悄悄跳过，也不能伪装成已覆盖全部义项。
