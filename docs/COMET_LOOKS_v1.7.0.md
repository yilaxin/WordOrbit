# 生活彗星外观 · v1.7.0

## 六类视觉

| 外观 | 颜色 | 主要形态 |
| --- | --- | --- |
| 霜蓝 | 冰白、青蓝 | 窄而较长、微弯很小 |
| 紫晶 | 淡紫、玫紫 | 更宽、更柔和的雾状尾与光晕 |
| 极光 | 薄荷绿、湖蓝 | 微弯、错开的丝带流光 |
| 琥珀 | 暖白、橙金 | 较短扇尾及较多金色微尘 |
| 玫瑰 | 浅粉、淡紫 | 相邻后逐渐分开的双束尾迹 |
| 银辉 | 银白、淡蓝灰 | 细而长、光晕克制的尾迹 |

均为艺术化生活记忆标记，不是天文分类。主场景与兼容模式共享颜色、宽度、长度、弯曲、分岔及微尘数量参数；选中保持原色，仅加强光晕和轮廓。相机、运动、悬停停泊、回忆卡及英文揭示规则不变。

## 选择与稳定性

添加时在当前可见分片统计各类型，优先推荐数量最少者；并列时随机。建议不遍历整个私有库，不保证其他分片不重复。标题下默认收起的外观区可选六款，或点“帮我选一个”；再次建议排除当前款。所有选择仅在保存成功后写入记录，失败/取消不改变已存内容。

新字段 `appearance` 仅接受 `frost`、`amethyst`、`aurora`、`amber`、`rose`、`silver`。缺少字段的旧记录按 ID 确定性分配，文字编辑、排序、分片与重启不影响外观；仅浏览不写库。编辑保存或备份导出时把该结果明确写入字段。未知字段值拒绝导入，不静默改色。

备份格式仍为 `wordorbit-comets` v1，字段可选，因此旧备份继续有效。外观随独立备份恢复；编号或内容相同的记录仍跳过，外观不参与内容去重指纹，恢复不覆盖现有记录。不包含在公共题库、我的星球或星云备份中，也不随 GitHub 同步。旧版 App 不认识新字段，建议升级后不要回到旧版编辑/重导出。

## 资源与操作

- 主场景最多 12 颗，继续使用同一个画布、三层各 36 段尾迹，微尘每颗不超过 9 点，不为类型增加独立场景。
- 编辑卡为静态内联 SVG，只有一个可选 Canvas2D 动态预览；默认折叠，不额外运行动画。
- 展开且预览可见、页面前台、系统允许动效时，预览最多约 24 帧/秒，像素密度最多 1.25。收起/关闭释放预览像素缓冲；编辑暂停主场景，取消恢复原播放状态。
- 没有新增图片下载、GPU 引擎、后台轮询或私人内容分析。原银河资产保持按需加载，离开彗星页面仍销毁主场景。

## 验证

`comets-appearance.test.cjs` 检查六类唯一且有界的参数、旧记录、自动建议、校验及备份去重。`comets-appearance.browser.cjs` 在 WebGL 和 Canvas 兼容模式中检查实际场景参数、手动选择、保存、备份往返、旧记录不写入、预览启停/释放、窄屏和公私数据隔离。继续运行原彗星记录、回忆、滚轮添加、资源释放、背景、离线缓存、主题星图和私人词库回归。所有记录均为隔离合成样例。
