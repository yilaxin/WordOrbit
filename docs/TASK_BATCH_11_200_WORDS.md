## 2. 逐词核对义项与来源

- 实际查阅 Cambridge、Collins、Merriam-Webster 等出版方的原始词条。技术义可补原始官方文档。搜索摘要、原书 OCR、构造一个存在的 URL 不等于查阅；导航或广告内容不等于定义，访问失败须另找可核实来源。
- 每个教学义项应有稳定的 `id`、`label`、`pos`、`aliases`、`concepts`、`source`、必要的 `construction` 及 `example.en/zh`；声明审核日期和学习范围。
- 纳入雅思阅读、听力、写作及一般学习中有用的常见含义，不限制每词两个义项；不同语义分开，同一语义的中文近义表达合理合并，不靠重复拆义凑数。
- 特别区分感受与引发感受的事物、动作与物品、名词与形容词、专业与日常、字面与常见比喻。参考第十批 grief 的“悲痛”和“令人悲痛的事”，以及 lossless 的数据无损/能量无耗。
- 常用多义不能因为旧译难映射就删掉。罕见、历史、专业用法可以放参考层，但须明确范围；“已完成”不等于穷尽词典所有历史义。
- 旧中文片段逐项映射到确切义项，或附具体 `context-required` / `restricted-verified` / `scope-excluded` 决定及原因、来源。不能用统一排除模板掩盖普通义项遗漏。
- 真正未核清的片段应标 `outside-scope-unresolved`、`complete=false`，交付时列明，不能把未决词伪装为已完整完成的 200 词。
- 本任务不批量改旧词 ID、原始译文或音标；覆盖层保留原始资料追溯。大小写、词形及英美差异须在教学内容中正确体现，不能随意合并不同单词。

## 3. 每义原创双语例句

- 每个义项分别写一句自然、具体的原创英文和准确中文译句，含目标词或正确屈折词形。搭配和词性应与该义项一致。
- 句子要能体现这个义项，不能看完仍无法区别同词其他义项；不要用词名谈词名代替自然使用，除非正在说明语言形式本身。
- 不照抄词典句子，不使用统一换词模板；与前十批全部英文句及本批其他句检查重复。
- 人工逐句核对语法、搭配、指代、时态、可数性和语义；中文准确保留否定、数量、对象、程度及语气。程序检查词形出现不代表语义已核对。

## 4. 近义干扰与练习验证

新词之间和新旧批次之间交叉检查同义、近义、上下位及多义交叉。共享 `concepts` 用于保守排除歧义，不表示所有句法都可互换。

干扰项只能来自其他可信词；英文选中文时排除本词任意真义，中文选英文时检查候选词的全部真义。干扰项不足应明确回忆自评，不编填充项。

至少验证：

- 新增恰好 200 个不同的正式公共词，与全部已有批次不重叠；源码、公开词表、本机筛选词表集合一致。
- 每义字段、唯一稳定 ID、词性、来源、原创双语句、目标词形和旧译追溯完整；未决、不完整词如实报告。
- 四轮各 50 个不重复的新词，覆盖本批全部新义项目标；同时用全量历史加新批词池生成选项，报告回忆降级次数。
- 具体近义对有明确回归断言；选项没有重复或真义混作错误项。
- 原题与选项快照稳定；答错追加到真正末尾；重复提交不重复记分；序列化后原样续做；全部基础和追加目标题完成才结束。
