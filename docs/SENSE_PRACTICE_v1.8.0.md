# v1.8.0：已审核义项接入说明

日期：2026-11-05。用户已要求先把现有结构化词用于正式学习。本版接入通过审核的子集，不等待全库编辑完成。

## 上线范围

结构化总数 1,130 词、2,826 组义项/例句；正式接入 1,125 词、2,786 组。`branch / trunk / stem / field / range` 五词继续阻断完整义项练习，原有普通练习保留。未结构化的 3,117 词继续使用基础词库。公共词总数 4,247、疑词 1，不追加重复词，不变更学习 ID。

`sense-ready-index.js` 是从公共捕获表与完整审核条件生成的小型 ID 绑定表，不能把学习导出当输入。`Build-SenseReadyIndex.cjs` 在编辑批次变化后重建索引，`sense-study-state.test.cjs` 检查索引与目录一致及五词阻断。

大型批次、目录和纯训练核心在首次词库/练习访问时顺序载入。桌面通过本地虚拟主机读取，网页版离线缓存预先保存全部依赖；不请求在线词典。完整目录只保留一份内存对象，不序列化到个人 catalog 缓存；首页和动画模块不主动载入例句。

## 练习与兼容

首页“义项全覆盖”和准备页对应题型是新的明确入口。每轮从该子集本轮未完成词中随机选最多 50 词，不足 50 不跨轮凑数；一轮全部完成后，再次主动开始才开启下一轮。传统整本遍历仍覆盖正式全书词表，不被悄悄缩小为该子集。

三个阶段依次为逐义语境、反向关联和多义检查，阶段内打乱。所有选择与目标题在生成时锁定；每题只计一次；错误追加到队尾，基础题优先完成。多选分开记录漏选和误选，各义项保留独立结果；回忆自评明确标记，单次熟悉义项不自动提升旧整词掌握等级。

`sense-study.js` 连接现有公共界面；`sense-study-state.js` 负责公共 ID、进度、恢复结构检查和独立义项历史。原来的词 ID、普通学习记录、收藏、个人笔记、标签和旧会话都保留。升级前已保存的旧会话固定使用旧显示语义，不重新抽取选项；新建的普通会话可使用新的公共审核释义。

所有解释区内容转义。作答前不展示主题、来源页；反向题隐藏音标和发音，中文标签里的英文搭配也隐藏，防止直接泄露答案。提交后展示目标义项及双语例句，可以展开完整学习范围和来源。

## 存储、恢复与清除

- 新模式仍使用公共学习状态中的 `lastSession`，另以 `senseStudy.version=1` 保存轮次及完成证据。义项历史从公共 `attempts` 中的 `sense-* / senseResults` 推导；旧单词作答不会自动补造义项历史。
- 恢复检查已锁定词、目标题、词 ID、队列、选项、重做根、结果和计数的一致性。异常训练保留供备份，不擅自重生成或继续判题。
- 版本 3 公共 JSON 导出加入义项进度和训练。导入前验证义项部分，再执行原词库导入；相同逐题记录去重，现有未完成训练优先保留。
- 三种清除继续使用产品内确认；相应完成证据随相关会话作答移除，其他轮次/日期保留。重算基础记录时，义项正确和错误都不改变旧整词等级。
- 不访问、迁移或同步任何私人星球、星云和生活彗星数据库。测试仅使用隔离合成记录。

## 验证

`sense-study-state.test.cjs` 检查接入范围、公共 ID、恢复损坏拒绝、逐义历史、提示遮挡及清除。`sense-study.browser.cjs` 检查真实 50 词生成、数字键、多选漏选、错题队尾、提交后音标、原样续练、JSON 导出/恢复/去重、清除、完成条件及旧训练兼容。`nebula-offline.browser.cjs` 另验证断网后首次加载义项模块并创建实际练习。原有词典、内存、星图、私人词库和彗星回归保留；桌面自检使用独立 `--data-dir` 并核对本地主机载入的 1,125/2,786 范围。

义项完整度仍以各批声明范围为准，不宣称穷尽所有专业、古旧或雅思可能用法。后续批次依然先编辑复核；只有通过完整审核并更新公共索引、兼容性和验证后，才扩大正式接入范围。
